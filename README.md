# ちゃっと安否確認

**バージョン 1.0.0**  
箱舟プロジェクトのTinyBoxとDelta Chatで使う、避難所向けの安否確認アプリです。避難者の氏名、安否、居場所、必要な支援、観察・トリアージの記録を、運営担当者どうしで共有します。

## 最初の使い方

1. 運営責任者に、TinyBoxのWi-FiとDelta Chatの設定を確認します。アプリは通信設備やメールアカウントを自動設定しません。
2. 信頼する運営担当者だけの**通常グループ**へ、`.xdc`ファイルを一度だけ添付します。ブロードキャストは使いません。
3. 全員が**同じ添付メッセージ**を開きます。同じファイルでも別に添付すると別の台帳になります。
4. 名簿にいるか検索します。新しい人は「＋ 新規登録」、既存の人は「詳細・更新」を押します。
5. 記録担当者、氏名、安否、滞在状況、場所、支援などを入力し、「この端末に保存して共有」を押します。
6. 別の端末でも同じ内容が見えるか照合します。初めは架空データで試してください。

**紙や口頭での受付も可能です。** 住民本人がスマートフォンを使えない場合は、運営担当者が代理入力します。

## 安否と滞在状況の違い

- **安否**：未確認、無事、要救助、病院搬送、連絡取れず。
- **滞在状況**：未確認、在所、一時外出、退所、搬送。

在所しているから無事、と自動では判断しません。分からない場合は未確認を選び、本人や担当者へ確認します。

## 主な機能

- 名簿の登録・検索・更新、安否の集計、支援が必要な人の確認。
- 受付・世帯番号、入退場ID、要配慮タグ、支援の担当・対応状況の記録。
- 観察した状態、トリアージ判定、判定者、観察時刻、タグ番号、救護・搬送の引継ぎ。
- 項目ごとの共同更新。同じ項目の同時更新は両候補を保持し、確認してから確定。
- 端末保存、未受付更新の再送、変更履歴、氏名なし集計、個人記録のJSON／CSV書き出し。
- 「ちゃっと入退場」の名簿取り込み。確認画面で人物を選択し、同じ人物IDの追加を防止。
- 15の表示言語と、アラビア語の右から左表示。
- 名簿の個人情報を一時的に画面から伏せる切替。

## 通信がないとき

インターネット接続がなくても、TinyBoxのローカルWi-Fi・メール配送などの経路で共有できます。**完全に切断しているときは、その端末だけへの保存です。** 再接続後はアプリを開き、未受付件数と別端末の表示を確認します。

未受付がなくなっても、相手への到達・閲覧・現場対応が確認できたわけではありません。急ぎの救護依頼は、対面や伝令でも伝えてください。端末時計のずれや未着があるため、人数と時刻は照合して使います。

## トリアージ記録

アプリは診断や自動判定をしません。観察と、訓練を受けた担当者の判定を記録します。観察・判定を保存する場合は、担当者と観察時刻が必要です。実物タグと照合し、状態が変わったら再評価します。黒の判定記録だけで、安否を死亡と認定・自動変更しません。

## ちゃっと入退場から名簿を取り込む

1. ちゃっと入退場で、JSONバックアップ、入退場CSV、または世帯・状態CSVを出力します。
2. 名簿の「ちゃっと入退場から名簿取り込み」を押し、ファイルを選ぶか内容を貼り付けます。
3. 氏名・人物ID・選択チェックを確認します。同じ人物IDは追加も上書きもしません。同姓同名は本人を確認してから選択します。
4. 必要なら最終滞在状況・場所の引継ぎを選び、担当者名を入力して確定します。

安否は必ず**未確認**で始めます。住所・電話・メール・医療メモは自動複写しません。人物IDを入退場IDとして保持します。UTF-8、20MBまで、履歴10万件まで、1回3000人までに対応しています。取り込み後の一括取消はありません。詳細は操作マニュアルの8章をご覧ください。

## 表示言語

日本語、英語、中国語（簡体字）、韓国語、ベトナム語、タガログ語、フィリピン語、ポルトガル語、ネパール語、スペイン語、フランス語、ドイツ語、アラビア語、インドネシア語、ロシア語。

上部の「表示言語」で切り替えます。設定は端末ごとに保存され、ほかの人には影響しません。氏名・メモなどの原文と、共有する状態値は変えません。翻訳データは同梱され、外部の翻訳サービスには接続しません。

## 個人情報と運営

全グループ参加者が全記録と履歴を閲覧・編集できます。担当者名は自己申告で、本人認証ではありません。機微な医療情報は、救護担当者に限定した別の通常グループで扱ってください。利用目的、閲覧者、保管期限を決め、必要以上の情報を記録しないようにします。

「表示を伏せる」は画面を隠すだけです。データの匿名化、アクセス制限、送信済み履歴の消去は行いません。修正前の値は履歴に残ります。個人記録のJSON／CSVには医療情報や全履歴が含まれる場合があるため、保存先と共有先を確認してください。

## 単体デモと地域行事

`index.html`を1個だけコピーし、ChromeやEdgeなどで開けば、インターネットなしで操作を練習できます。架空データ6件を表示し、登録・更新・取り込み・書き出し・言語切替を試せます。他端末への共有は行いません。「デモを初期状態に戻す」で、このデモの入力だけを初期化できます。

訓練・祭り・清掃などでは、在所を参加、退所を退出として利用できます。行事ごとに別の添付を使い、災害の実記録とは分けてください。

## 制限と確認状況

- 別アプリとの自動通信・継続同期、QRの読取り、人物の自動名寄せ、管理者専用の編集制限はありません。
- 安否確認の出力JSONを復元する機能、全端末の記録消去、一括取消、添付済み旧版台帳の自動置換・移行はありません。
- 共同更新、取り込み、15言語、表示方向、入力保持などは模擬環境で検証しました。
- 実機Delta Chat・TinyBox、大量名簿の実機性能、すべての翻訳の母語話者・医療専門家による校閲は未検証です。本番前に利用環境と用語を確認してください。
